YCUVE 관리자 가이드

이원주 작품 사이트 사용법

작품 이미지 업로드, 작품 등록, 삭제, 화면 표시 방식까지 한눈에 보기 쉽게 정리한 모바일용 가이드입니다.

1. 작품 이미지 업로드 2. 작품 1개 등록 3. 여러 작품 한 번에 등록 4. 작품 삭제 5. 화면 표시 방식 6. 작업 전 주의사항
1

1. 작품 이미지 업로드

1)

crop.html 페이지를 엽니다.

2)

비밀번호를 입력합니다.

3)

이미지 선택을 눌러 작품 이미지를 선택합니다.

4)

필요하면 화면에서 이미지 위치와 크기를 확인합니다.

5)

미리보기를 누릅니다.

6)

ImageKit 업로드를 누릅니다.

7)

업로드가 끝나면 URL 복사를 누릅니다.

업로드 파일명은 날짜, 시간, 번호가 함께 들어갑니다.

예시
작품명-20260603-2145-0001-full-1600.webp
2

2. 작품 1개 등록

1)

메인 페이지에서 관리자 페이지를 엽니다.

2)

비밀번호를 입력합니다.

3)

작품 등록 추가 영역으로 이동합니다.

4)

카테고리, 연도, 작품 제목, 작품 설명을 입력합니다.

5)

작품 이미지 링크에 crop 페이지에서 복사한 URL을 붙여넣습니다.

6)

작품/유튜브 반영을 누릅니다.

등록 후 입력값은 자동으로 비워집니다.

3

3. 여러 작품 한 번에 등록

1)

crop 페이지에서 여러 이미지를 차례대로 업로드합니다.

2)

오른쪽 URL 목록에 업로드한 URL들이 쌓였는지 확인합니다.

3)

URL 복사를 누릅니다.

4)

관리자 페이지의 여러 작품 이미지 링크에 붙여넣습니다.

5)

작품 제목, 설명, 카테고리, 연도를 입력합니다.

6)

URL 목록 일괄 추가를 누릅니다.

여러 장을 일괄 추가하면 작품 제목 뒤에 번호가 자동으로 붙습니다.

예시
복의 율동 01
복의 율동 02
복의 율동 03
4

4. 작품 삭제

1)

관리자 페이지의 반영할 기존 작품에서 삭제할 작품을 선택합니다.

2)

선택 작품 삭제를 누릅니다.

3)

삭제한 작품은 메인 화면과 선택 목록에서 보이지 않습니다.

새 작품 추가 상태에서 삭제 버튼을 누르면 현재 입력값만 비워집니다.

5

5. 화면 표시 방식

메인 카드에서는 이미지가 보기 좋게 일부 잘려 보일 수 있습니다.
작품을 클릭하면 전체 이미지가 보입니다.
crop 페이지는 원본 비율 이미지를 업로드합니다.
6

6. 작업 전 주의사항

작업 전 페이지를 새로고침합니다.
바뀐 내용이 바로 안 보이면 Ctrl + F5로 강력 새로고침합니다.
같은 URL을 다시 등록하면 새 작품으로 중복 추가하지 않고 건너뜁니다.
여러 명이 작업해도 파일명에 날짜와 시간이 들어가서 ImageKit 파일명이 헷갈릴 가능성이 줄어듭니다.
