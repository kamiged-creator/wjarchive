# Artist Portfolio Template

판매용 작가 포트폴리오 템플릿 작업 브랜치입니다.

## 원칙
- 운영 중인 원본 `main` 브랜치는 변경하지 않습니다.
- 실제 작가 이름, 작품, 이메일, 도메인, 검색엔진 인증값을 판매본에 포함하지 않습니다.
- 작품 관리, 책 소개, 팝업, 사이트 문구, 작가 소개, 관리자 기능은 유지합니다.
- 구매자가 자신의 이름·이미지·연락처·관리자 이메일·Supabase 설정을 넣어 사용할 수 있도록 범용화합니다.

## 작업 단계
1. 개인/브랜드 정보 제거
2. 샘플 작가·샘플 작품 데이터로 교체
3. 책 소개 사용/숨김 옵션
4. 관리자 인증과 비밀번호 재설정 범용화
5. Supabase / ImageKit 설정 분리
6. 색상·로고·작가명 설정화
7. 설치 가이드와 판매용 데모 정리
8. 모바일·PC 최종 QA

현재 브랜치: `template/artist-portfolio-v1`
