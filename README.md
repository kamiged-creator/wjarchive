# Artist Portfolio Template

작가·공예가·사진가·일러스트레이터가 사용할 수 있는 모바일 중심 포트폴리오 템플릿입니다.

## 포함 기능

- 반응형 작가 포트폴리오
- 작품 카테고리 및 상세 뷰어
- 관리자 페이지
- 작품 등록·수정
- 메인/작가소개 문구 관리
- 팝업 관리
- 책 소개 목록 및 상세페이지
- 책 소개 ON/OFF
- 관리자 이메일 비밀번호 재설정
- ImageKit 이미지 작업 연동 구조
- Supabase 데이터 저장 구조

## 템플릿 설정

구매자가 주로 수정하는 파일은 `template-config.js` 하나입니다.

서버 설정은 Vercel 환경변수로 분리합니다. 실제 운영 서비스의 API 키, 관리자 이메일, 도메인 값은 판매본 코드에 포함하지 않습니다.

자세한 설치 순서는 `TEMPLATE_SETUP_KO.md`를 참고하세요.

새 Supabase 프로젝트의 테이블과 접근 정책 초안은 `supabase-setup.sql`에 있습니다. 구매자 계정에서 설치와 저장 흐름을 검증하기 전까지는 판매 준비용 초안입니다.

## 개발 브랜치

`template/artist-portfolio-v1`

운영 중인 원본 `main` 브랜치와 분리해서 작업합니다.
