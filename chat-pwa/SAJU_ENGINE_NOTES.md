# 복작소 AI 사주 · 만세력 엔진 1차 개발 메모

## 현재 상태 (배포 전 개발 브랜치)
- 작업 브랜치: `feature/saju-manse-engine-v1`. 운영 사이트 `main`에는 병합하지 않는다.
- 화면: `saju-chat.html` 기존 다크 테마와 입력 폼 유지. 입력 확인 뒤 계산 결과 카드를 표시한다.
- 계산 어댑터: `saju-engine.js` (브라우저에서 `manseryeok@2.0.0` 모듈을 동적으로 불러온다).
- 개인정보: 입력한 생년월일·출생시간은 계산을 위해 브라우저 메모리에서만 사용하고, 외부 API로 전송하지 않는다. *계산 라이브러리의 자바스크립트 파일 다운로드 요청*은 CDN으로 발생한다.
- 사주팔자: 년주(입춘 기준), 월주(절기 기준), 일주, 시주, 오행(겉 8글자) 표시.
- 양력/음력/윤달 지원. 잘못된 날짜는 라이브러리가 오류로 거부한다.
- 출생시간 모름: 정오로 나머지 3주를 계산하되 *시주를 미상*으로 표시하고, 절기/일주 경계일 가능성을 추가 안내한다.
- 대운: 성별과 정확한 시각이 입력된 경우에만 라이브러리가 제공하는 계산 결과에서 일부를 참고용으로 제시한다.
- 채팅: 실제 만세력 결과에 근거한 전통 명리 풀이 문장만 생성한다. 자유 대화형 AI 모델은 아직 미연결.
- 모든 풀이와 대운은 전통적 해석이지 의료·투자·인생사 예측이 아니다.

## 계산 기준과 남은 과제
1. 한국 표준시(기본 KST), 자정 일 경계(`dayBoundary: 'midnight'`), 진태양시 보정 OFF. 표준시 역사와 출생지 경도는 사용자가 설정할 수 있도록 추후 확장.
2. 외부 CDN `https://esm.sh/manseryeok@2.0.0?bundle` 접근이 불가능할 때는 계산 불가를 표시하고 추측 결과를 내지 않는다. 출시 전에는 로컬 번들로 고정하고, 라이선스 고지를 함께 묶는 것을 권장.
3. 계절·절입 시각과 한국천문연구원 자료의 교차검증, 23시 자시 관법 설정, 해외 출생 지역별 시간대, 유료 상담 단계의 해석 품질 검수는 미완료.
4. 궁합은 두 사람의 4주만 나란히 계산하며 합충 및 궁합 점수화는 아직 하지 않는다.
5. 100회 배포 제한 해제 후 운영에 올리기 *전*, 별도 미리보기에서 실제 npm 라이브러리를 불러와 휴대폰 네트워크/삼성 인터넷 및 절기 경계 사례를 확인해야 한다.

## 수동 인수 테스트
- 1992-10-24 05:30 양력: 라이브러리 공식 예시 `임신 / 경술 / 계유 / 을묘`.
- 1992년 음력 9월 29일 05:30: 위 양력 사례와 동일한 네 기둥.
- 2020년 윤4월 1일: 양력 `2020-05-23`로 환산.
- 2024년 입춘 시각 직전/직후: 연주·월주 경계 판정 확인.
- 출생시간 모름: 시주는 `미상`, 오행 겉글자 합계 6.
- 윤달이 아닌 날짜에 윤달 체크: 정확한 오류 안내.
- 실서비스: 읽기 전용 테스트 후 배포. 원래 PWA 화면·채팅방·클럽 데이터 변경 여부 확인.

## 자동 단위 검증
```bash
cd chat-pwa
node --test tests/saju-engine.test.cjs
```
