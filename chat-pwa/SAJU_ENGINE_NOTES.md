# 복작소 사주 만세력 엔진 · 배포 전 검증 문서

## 작업 상태
- 개발 브랜치: `feature/saju-manse-engine-v1` (운영 `main`에는 병합하지 않음).
- 구현 파일: `saju-engine.js`, `saju-chat.html`, `tests/saju-engine.test.cjs`.
- 사주팔자: 입춘 기준 연주, 절기 기준 월주, 일주, 시주 및 한자 표시.
- 양력/음력/윤달 변환, 일간·음양·오행(겉 글자 8개, 출생시간 미상이면 6개), 대운 지원.
- 사주채팅 입력 완료 후 각 사람의 사주팔자와 기본 전통 명리 풀이, **오늘의 일진·현재 세운**을 카드로 표시.
- 서윤 궁합 상담은 두 사람의 실제 만세력 일간과 겉글자 오행을 교차 비교한다. 합충·점수화·결혼 성패 예측은 미구현이며 사실처럼 주장하지 않는다.
- 아라·도윤·서윤·지안의 분야별 설명 톤을 구분했다. 각 문장은 실제 계산 객체를 입력으로 쓰는 규칙 기반 템플릿이며 **아직 자연어 자유대화 AI는 아니다**.
- 상담 텍스트창: 자유 질문에 대응하는 언어모델은 아직 없음. 질문 텍스트를 해석하지 않고 같은 사주 계산에 근거한 기본 풀이만 출력하며 한계를 명시함.

## 출생 지역 및 진태양시
- 출생 지역 필드는 선택사항. 기본 `보정하지 않음`에서는 기록된 국내 표준시각 그대로 사주를 계산한다.
- 선택 가능한 출생 지역: 서울(126.9780), 인천(126.7052), 대구(128.6014), 부산(129.0756), 대전(127.3845), 광주(126.8526), 제주(126.5312). 시 중심부 경도의 근사값이다.
- 경도 직접 입력은 국내 범위 `124..132°E`에서 허용한다.
- 지역 선택과 출생시간 입력이 모두 있는 경우에만 라이브러리의 `trueSolarTime`(경도, 균시차, 과거 표준시/DST)을 켠다.
- 출생시간을 모르면 보정을 적용하지 않고 **시주를 미상**으로 둔다. 절기·일주 경계에 걸린 경우 결과에 불확실성 안내를 띄운다.
- 기본 일주 경계: **자정**. 23시 자시 시작/야자시·조자시 학파 차이는 설정되지 않았다.
- 한국 표준시를 기본으로 가정한 계산이므로 **해외 출생을 지원하지 않는다**. 역사적 시간대·윤달·절입 경계는 실제 라이브러리 통합 검증이 필요하다.

## 일진·세운
- 브라우저에서 날짜를 `Asia/Seoul` 기준으로 읽고, 해당 날 12:00의 만세력 **년주·월주·일주**를 추가 계산한다.
- 일진과 세운은 현재 날짜의 전통 간지에 해당하며, 출생 원국은 아님. 1월 1일이 아니라 입춘 시각을 경계로 세운 간지가 바뀐다.
- 천간 오행끼리 같은 기운·생극 관계를 산출하고, 실제 건강·자금·연애 사건을 예측하지 않는 설명과 함께 표시한다.
- `flowReading`은 상징적 참고 풀이만 제공하며 **길흉 점수, 재산 예측, 확정된 미래 사건**은 생성하지 않는다.

## 의존성과 개인정보
- 계산용으로 `manseryeok@2.0.0`(MIT, Yoohyojun) 모듈을 `https://esm.sh/manseryeok@2.0.0?bundle`에서 다운받는다. 출생 정보를 URL이나 서버 API로 보내지는 않지만, CDN 로딩 요청은 발생한다.
- 출생 정보는 현재 탭의 JS 메모리만 사용하며 상담 대화(sessionStorage)에 붙이지 않는다. 사용자가 **직접 입력한 채팅 질문**은 기존 체험 채팅의 sessionStorage에 저장됨.
- 실제 배포 전에는 가능하면 라이브러리 자산을 저장소 로컬 번들로 고정하고 MIT 고지와 함께 배포한다. CDN이 불가능하면 추측해서 사주 결과를 만들지 말고 오류를 표시한다.

## 2026-10-18 AI 텍스트 사주상담 (개발 미리보기 전용)

- 서버: `chat-pwa/api/saju-ai.js` (Vercel Node.js). 화면: `chat-pwa/saju-chat.html`.
- 네 명의 텍스트 상담사별 톤으로 현재 질문에 대답하며, 기본 만세력 풀이와 **실제 외부 AI 답변을 화면에서 구분**한다. 하린 Simli 음성상담은 변경하지 않는다.
- 외부 AI 호출은 사용자가 명시적 체크박스에 동의하고, 서버 설정 및 시험 비밀번호 확인을 통과했을 때만 발생한다. 체크하지 않으면 기존 로컬 사주 기본 풀이를 보여준다.
- 전송 데이터: **출생 날짜·출생 시각 원본 제외**, 계산된 연·월·일·시주, 일간, 오행, 선택 분야, 필요한 경우 현재 일진·세운, 궁합 상대방의 동일한 계산 결과, 질문과 최근 최대 4개 대화 메시지. 질문/메시지에 이용자가 직접 쓴 개인정보는 전송될 수 있다는 안내를 표시한다.
- 모델: `gpt-4.1-mini`, 한 번의 응답 최대 450 토큰 설정, `store:false`; 실제 비용 발생 가능. 서버 변수 외에 API 키는 소스/HTML에 두지 않는다. 서버에서 프롬프트를 작성하며 결과는 사실 보장 없는 전통적 참고 해석으로 제한한다.
- 비용 안전장치: 서버 환경 `VERCEL_ENV=preview` 및 `SAJU_AI_ENABLED=1` 및 `OPENAI_API_KEY` 및 최소 8자 `SAJU_AI_TEST_PIN` **모두 필요**. 본 API는 production에서 항상 503(미구성) 처리, 시험 코드 일치 확인, 동일 origin 검사, 입력 제한, 최대 450 completion 토큰, 호출 실패/시간 초과 처리, 인스턴스 메모리 기반 시간당 12회/IP 임시 제한을 둠.
- 주의: 인스턴스별 제한은 서버리스 여러 인스턴스에 걸쳐 일관성을 보장하는 **운영용 분산 rate limit이 아님**. 정식 서비스 전에는 로그인 또는 권한 검증, Vercel WAF/속도 제한 또는 KV 저장소, 비용 한도, 개인정보 처리방침·동의 설계가 필요.
