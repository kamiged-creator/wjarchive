# 복작소 첫 방문 회원 등록 — 미리보기 / 출시 전 필수 점검

2026-10-13 작성. 구현 파일: \`chat-pwa/signup-preview.html\`.

## 구현 완료 (화면 검증용)

- 이름(비공개), 채팅 닉네임(공개), 휴대전화 번호 입력, 프로필 사진(선택) UI
- 사진은 선택한 기기 안에서만 미리보기, 최대 3MB 이미지 체크
- 이름·닉네임·전화번호 형식 및 안내 체크 확인, 전화번호 마스킹 결과 화면
- 테스트 표시를 지속적으로 노출. **문자 발송 없음 / 인증 없음 / 서버 전송 없음 / 브라우저 저장 없음 / 가입 완료 아님**
- 기존 메인화면, PWA 설치, 관리자 및 채팅방 흐름은 변경하지 않음

## 실서비스 전환 필수 항목

1. **문자 인증 제공업체 연결 및 운영 비용 승인:** 공급업체, 발신번호, 국가·번호 정책, 테스트/운영 키, 전송 요금 및 이용약관 확인
2. **별도 회원·인증 API:** 전화번호 E.164 정규화; 인증번호는 서버에서 난수로 생성, 해시 보관, 5분 만료, 횟수·속도 제한, 재전송 제한, 남용 방지; **SMS 인증 전에는 가입 성공 처리 금지**
3. **개인정보 최소화:** 전화번호, 실명은 공개 채팅 응답과 URL·로그·localStorage에 절대 포함하지 않음. 서버 측 제한된 테이블에 암호화 보관; 인증된 관리자만 최소한으로 접근. 사용자 계정 식별은 기존 임의 ID 이용
4. **기존 회원 전환:** 기존 \`bokjaksoChatSharedProfileV1\`의 프로필 ID/토큰을 먼저 검증하여 **기존 프로필과 닉네임/채팅방 기록을 유지한 상태**로 실명·전화 인증을 추가. 휴대폰 번호만으로 무인증 계정 연결 금지
5. **개인정보 안내 및 동의:** 운영자가 실제 목적·항목·보유기간·처리위탁(SMS·이미지업체)·동의 거부 영향·개인정보처리방침과 탈퇴/삭제 절차를 확정; 동의 내역 버전 및 시각 기록
6. **프로필 사진:** 기존 ImageKit 업로드 흐름 사용하되 기존 \`chat_profiles\` 연결 및 변경 권한 확인; 거절/실패 사진 정리; 공개 범위를 설명
7. **가입 게이트:** 백엔드 API·DB·SMS 준비 전까지 \`signup-preview.html\`만 테스트 가능. 준비·검증 후 메인 진입 시 \`chat_profiles\`와 가입 상태를 서버에서 판단하여 미가입자에게만 안전하게 안내. 앱 설치 여부와 가입 여부는 별개
8. **테스트:** 신규 회원 SMS 인증→프로필 사진→일반 채팅→재방문→기기 변경→계정복구→클럽 승인→탈퇴; SMS 오류, 중복 번호, 번호 변경, 기존 프로필 자동 연결, 비동의, CSRF/XSS, API 무단 호출 확인

## 주의

\`signup-preview.html\`은 사용자에게 '실제 이름이나 번호를 넣지 말라'고 표시한다. 앱 화면만 테스트할 수 있으며 운영 회원을 만들지 않는다. 현재 인증 및 개인정보 서버 저장을 연결하지 않았으므로 새 회원에게 등록 의무를 부과하지 않는다.
