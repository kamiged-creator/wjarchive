# 복작소 채팅 독립 PWA
- 별도 Vercel 프로젝트의 루트 디렉터리: `chat-pwa`
- 시작 화면: `/chat.html`, 설치 범위: `/`
- 이미지: 사용자가 제공한 福 말풍선 아이콘 (192px/512px)
- Service worker는 채팅과 개인정보를 캐시하지 않음; 오프라인 안내만 캐시
- 기존 복작소 홈페이지와 별도 PWA 및 설치 주소
- **현재 백엔드 공유**: /api/* 프록시가 기존 bokjakso.com API를 호출하므로 채팅방/기존 대화는 유지되지만 서버 측 의존성이 있음
- 별도 도메인으로 이동하므로 자동 입장·프로필 및 푸시 알림은 새 주소에서 한 번 다시 설정해야 함
- 관리자: `/admin-login.html`에서 기존 복작소 관리자 인증으로 로그인
- DNS 및 독립 데이터베이스 분리는 별도 단계

## 메인 화면 탭 (설계 1단계)
- `채팅방`은 기존 채팅방 목록 및 입장 기능을 그대로 사용합니다.
- `복작소 클럽`은 관리자 승인 회원제의 **안내 화면만** 제공하며 가입·승인 API는 아직 연결되지 않았습니다. 실제 회원 등록, 관리자 심사 및 전용 채팅은 백엔드 구현 후 열어야 합니다.
- `내 정보`는 기존 채팅 공통 프로필 편집기를 재사용합니다.
- 이 변경은 초안 PR에만 있으며, 운영 배포 또는 백엔드 데이터 변경은 하지 않습니다.
